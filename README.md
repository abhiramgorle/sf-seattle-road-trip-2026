# SF → Seattle Road Trip 🚗

**San Francisco to Seattle · September 2–7, 2026 · 6 Days · 2 People**

An interactive road trip guide covering the best of the California coast, Oregon wilderness, and Pacific Northwest.

🌐 **Live site:** [abhiramgorle.github.io/sf-seattle-road-trip-2026](https://abhiramgorle.github.io/sf-seattle-road-trip-2026/)

---

## Route

```
San Francisco → Yosemite Valley → Knights Ferry
→ Avenue of the Giants → Humboldt Redwoods → Trinidad
→ Fern Canyon → Jedediah Smith Redwoods → Grants Pass
→ Crater Lake → Smith Rock → Bend
→ Mt. Hood → Timberline Lodge → Multnomah Falls → Tenino
→ Mt. Rainier Paradise → Seattle
```

**~1,550 miles · ~32 hrs driving · ~$950/person all-in**

---

## What's on the site

- **Interactive map** — color-coded route by day (Leaflet + CARTO Voyager tiles)
- **Day-by-day itinerary** — every stop with times, durations, and costs
- **Google Maps navigation buttons** — one tap to navigate to any stop
- **Stop highlights** — ⭐ Main Stops · Don't Miss · Pre-Book Required
- **Pre-book checklist** — permits, campgrounds, and passes with direct booking links
- **Weather forecast** — per-day temps, fire alerts, and closure status (rechecked Aug 26)
- **Budget breakdown** — per-person cost for all 6 days
